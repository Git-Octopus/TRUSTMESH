### 2.2 Event-to-Database Mapping Reference
The listener automatically handles the following events:
- **`ClaimVerified(claimId, claimant, verifier, timestamp)`**:
  - Sets `Claim.status = 'approved'` (or `'VERIFIED'`).
  - Stores `Claim.onChainTxHash = event.transactionHash`.
  - Creates a record in `Verification` collection with verifier wallet, timestamp, and tx hash.
- **`ClaimRejected(claimId, claimant, verifier, reason, timestamp)`**:
  - Sets `Claim.status = 'rejected'`.
  - Creates an audit record in `Verification` with `approved = false` and comments = `reason`.
- **`VerificationRevoked(claimId, verifier, timestamp)`**:
  - Sets `Claim.status = 'revoked'`.
- **`VerifierRegistered(verifier, timestamp)`**:
  - Updates matching `User` record to `role: 'verifier'`.

### 2.3 On-Chain vs Off-Chain Data Discipline
- **Off-chain (Mongo/Multer):** Full title, rich markdown description, original files/images, user profile, OTP state.
- **On-chain (`TrustMesh.sol`):** 
  - `claimType`: string (e.g. `"Skill"`, `"Experience"`, `"Project"`).
  - `referenceHash`: SHA-256 hex string generated by your `hashService.js` from the uploaded evidence.
  - `claimId`: uint256 counter. Store this in your `Claim` schema as `onChainClaimId`.

## 3. Handover to Dev A (Frontend Lead)

### 3.1 Importing Contract ABI & Address
Contract configuration is auto-generated at `client/src/contracts/TrustMesh.json`:
```javascript
import TrustMeshArtifact from '../contracts/TrustMesh.json';

// Initialize Ethers contract instance with MetaMask signer:
const provider = new ethers.BrowserProvider(window.ethereum);
const signer = await provider.getSigner();
const trustMeshContract = new ethers.Contract(
  TrustMeshArtifact.address,
  TrustMeshArtifact.abi,
  signer
);
```

### 3.2 Key Contract Calls for Frontend Screens

#### A. Create Claim Flow (Screen 3)
When the user submits a claim and receives the computed SHA-256 hash from Dev B's backend:
```javascript
const tx = await trustMeshContract.createClaim(claimType, sha256EvidenceHash);
const receipt = await tx.wait();

// Read claimId from ClaimCreated event args
const createdEvent = receipt.logs
  .map(log => trustMeshContract.interface.parseLog(log))
  .find(e => e && e.name === 'ClaimCreated');
const onChainClaimId = Number(createdEvent.args.claimId);
```

#### B. Verifier Dashboard: Approve Claim (Screen 5)
When an authorized verifier clicks **Approve**:
```javascript

  // Show "Confirming on-chain..." toast

  // Show "Claim verified successfully! Tx: " + receipt.hash

  handleContractError(error);
```
