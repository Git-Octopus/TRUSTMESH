# TrustMesh Demo Script

1. **User Sign Up & Login**:
   - Register account, receive OTP, verify email.
2. **Claim Creation & Evidence Upload**:
   - Submit claim with evidence file upload to off-chain storage.
3. **Smart Contract Verification**:
   - Verifier approves claim on-chain using MetaMask / Ethers.js.
4. **Trust Score Update**:
   - Web3 listener detects contract event and updates trust score in backend & UI.
